# VBOM0100 — Cabeçalhos de Estrutura (BOM)

> O cadastro de plataforma que versiona a estrutura do produto: **tipo** (engenharia/manufatura) e **status** (rascunho → aprovada → obsoleta) por item.

## Objetivo

Manter os cabeçalhos versionados das estruturas, garantindo que cada item tenha uma versão vigente aprovada e um histórico de versões obsoletas.

## Pré-requisitos

- Item cadastrado ([VENT0200](/engenharia/vent0200)).

## Passo a passo

1. Crie o **cabeçalho** para o item, escolhendo o **Tipo** (Engenharia/Manufatura, padrão Manufatura) e a **Vigência**.
2. Conduza o **Status**: **Rascunho** durante a edição, **Aprovada** para liberar, **Obsoleta** ao aposentar.
3. Antes de aprovar, confira os componentes e suas vigências na estrutura do produto.

## Status

| Status | Significado |
|--------|-------------|
| **Rascunho** | Em edição — não deve alimentar MRP/produção. |
| **Aprovada** | Vigente — liberada para uso. |
| **Obsoleta** | Aposentada — mantida como histórico. |

## Observações importantes

- Só a versão **Aprovada** deve ser consumida por MRP e ordens de produção.
- Esta rotina e a **[VENG0300](/engenharia/veng0300)** cobrem o versionamento da BOM — use a que aparecer no seu menu.
- Não torne uma versão obsoleta antes de confirmar qual estrutura substituirá a vigente.
- Alterar o cabeçalho não substitui a manutenção dos componentes da estrutura.
